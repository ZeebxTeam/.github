# O Projeto Zeebx

O projeto Zeebx consiste em um conjunto de recursos de software relacionados ao console brasileiro Zeebo, destinado à preservação e acesso a história do console como um todo.

Dentre estes recursos estão:
- Um emulador Zeebx - que busca entregar a melhor e mais completa experiência Zeebo sem a necessidade do console físico
- Ferramentas de visualização de assets e modelos 3D - para estudo e maior conhecimento sobre os jogos e como eram desenvolvidos para o console
- Ferramentas de modding - para oferecer uma interface simples e intuitiva para projetos de melhoria gráfica nos games
- Servidores - Para recuperar recursos online de avatares e rankings em jogos

Cada um desses projetos corre em código aberto, de forma aberta e transparente para os interessados, estou atento à feedbacks, bug reports e também analiso PRs de outros devs interessados em ajudar!

## Disclaimer

Zeebx como um todo (emuladores e outros recursos), são completamente open source e gratuitos.
Não será cobrado pelo uso do emulador em nenhum momento, o projeto é livre e não está aberto no momento a nenhum tipo de apoio financeiro.
